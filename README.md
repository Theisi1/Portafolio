# Portafolio Académico — Isaac González

🌐 **Sitio web:** [https://theisi1.github.io/Portafolio/](https://theisi1.github.io/Portafolio/)

Este portafolio recopila mis actividades, proyectos y certificaciones como estudiante de **Ingeniería en Ciencias de la Computación** en la **Escuela Politécnica Nacional (EPN)**.  
El sitio fue construido utilizando el tema [**al-folio**](https://github.com/alshedivat/al-folio) adaptado para GitHub Pages.

## 📑 Contenido
- 🏠 **Inicio:** Presentación general y resumen personal.  
- 👨‍💻 **Sobre mí:** Información académica y perfil profesional.  
- 🧮 **Portafolio Académico:** Actividades desarrolladas (incluye ejercicios como la conversión IEEE-754 de 138.91).  
- 🎓 **Certificados:** Evidencias de formación, como el curso de Python.  
- ✉️ **Contacto:** Correo, LinkedIn y GitHub.

## ⚙️ Tecnologías
- **Jekyll + GitHub Pages**
- **Tema:** al-folio
- **Lenguajes:** HTML / Markdown / CSS / YAML

## 🚀 Cómo ejecutar localmente
```bash
git clone https://github.com/Theisi1/Portafolio.git
cd Portafolio
bundle install
bundle exec jekyll serve
```
Abrir en: **http://localhost:4000/Portafolio/**
